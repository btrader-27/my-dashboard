My Daily Tasks

One-time setup using a free Google Apps Script. Takes 2 minutes and works from anywhere.

1
In your Google Sheet go to Extensions → Apps Script
2
Delete everything and paste this code:

function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet()
    .getSheetByName("Tasks");
  var rows = sheet.getDataRange().getValues();
  var csv = rows.map(r => r.join(",")).join("\n");
  return ContentService.createTextOutput(csv)
    .setMimeType(ContentService.MimeType.TEXT);
}
3
Deploy → New deployment → Web app
Set "Execute as" = Me
Set "Who has access" = Anyone
Click Deploy → copy the URL
4
Paste the URL into the box above and click Load My Tasks
